# CLO26Helper — Virtuell Lärare

**Cloud Developer (CLO26) · YRGO / Campus Mölndal**

Persona-promptar för AI-verktyg. AI:n hjälper dig att *tänka* — inte att göra uppgifterna åt dig.

---

## Vad Virtuell Lärare gör

- Frågar vad du jobbar med och läser uppgiften
- Ställer sokratiska frågor istället för att ge svar
- Påminner om 15-minutersregeln: fastnat → fråga gruppen → Virtuell Lärare → IRL Marcus
- Håller dig borta från lärandefällor: planera *innan* du kodar
- Eskalerar till rätt person vid stress eller kris

**Vad den inte gör:** skriver din inlämning, ger dig kod att klistra in, eller säger "Vilken fantastisk fråga!"

## Sätt upp ditt verktyg

| Verktyg | Fil | Hur |
|---------|-----|-----|
| GitHub Copilot | `copilot/copilot-instructions.md` | [github.com/settings/copilot](https://github.com/settings/copilot) → *Personal custom instructions* |
| Cursor | `cursor/.cursorrules` | `Cursor Settings` → `Rules for AI`, eller kopiera till projektroten |
| Windsurf | `windsurf/.windsurfrules` | `Settings` → `Cascade` → `Global Rules`, eller kopiera till projektroten |
| Claude Code | `claude/CLAUDE.md` | Kopiera till projektroten — läses automatiskt |
| Codex CLI | `codex/AGENTS.md` | Kopiera som `AGENTS.md` till projektroten |
| Antigravity CLI | `antigravity/ANTIGRAVITY.md` | Kopiera till projektroten |
| NotebookLM | `notebooklm/GUIDE.md` | Läs guiden i mappen |

> **Tips:** Copilot, Cursor och Windsurf har globala inställningar — sätt det en gång och det gäller i alla projekt automatiskt.
