# Cloud Developer — Campus Mölndal / YRGO

## Vad är detta?
En AI-driven lärarworkspace för YH-utbildningen **Cloud Developer** på Campus Mölndal, i samarbete med YRGO. Utbildningen är 2 år (400 YH-poäng) med start Augusti 2026.

## Utbildningens kursplan

### 1. Grundläggande OOP i C# (25 yhp)
Syntax, flöde, logik i C#. Clean Code: namngivning, klasser, metoder, variabler. OOP-koncept: objekt, arv, polymorfism, datastrukturer. Verktyg: Git, Markdown, felsökning med AI.

### 2. Databashantering och -design (20 yhp)
Datamodellering med UML. SQL & CRUD. MySQL (relationsdatabaser) + MongoDB (dokumentdatabaser). Avancerade SQL-frågor, JOIN, subfrågor. Säkerhet, autentisering, backup.

### 3. Fördjupad OOP i C# (25 yhp)
Design Patterns, refactoring, UML-diagram. Entity Framework för databaskopplingar. Kanban introduceras. Modulär och underhållbar kod.

### 4. Test och kvalitetssäkring (30 yhp)
TDD (Test-Driven Development). Unit-tester (NUnit/xUnit/MSTest). Testbar kod med Clean Code + designmönster. User Stories, Gherkin, SCRUM (backlog, estimering). Statisk kodanalys.

### 5. Introduktion till cloudutveckling (10 yhp)
IaaS, PaaS, SaaS. Azure, AWS, GCP - grunderna. Provisionera virtuell server via terminal.

### 6. Grundläggande molnapplikationer (40 yhp)
CI/CD (Continuous Integration). Docker och containerteknologi. Driftsätta containerbaserade + webbapplikationer. Molntjänster för autentisering och datalagring.

### 7. Konsultmässighet och kommunikation (10 yhp)
Självledarskap, retorik, kommunikationsmodeller. Kundmöten, behovsanalys, lösningsförslag. Gruppdynamik, teamets utvecklingsstadier.

### 8. Molnapplikationer fördjupning (40 yhp)
Infrastructure as Code (IaC): Terraform, Bicep, ARM-mallar. CI/CD avancerat. Monitorering i molnet. Säkerhet och nätverksoptimering. Containerbaserad arkitektur.

### 9. Skalbara molnapplikationer (40 yhp)
Continuous Delivery & Continuous Deployment. Serverless: Azure Functions, AWS Lambda. Horisontell skalning, lastbalansering. Bash/PowerShell automation. Robusta arkitektoniska mönster.

### 10. Kubernetes (20 yhp)
Containerorkestrering i kluster. YAML-manifest och Helm Charts. Ingress Controllers, hög tillgänglighet. Secrets/säkerhet. Kubernetes i CI/CD-pipeline.

### 11. Examensarbete (40 yhp)
Självständigt projekt med ny teknik/metodik. Teknisk dokumentation och rapport.

### 12. LIA - Lärande i arbete (100 yhp)
20 veckor praktik. C#/.NET backend, Docker, CI/CD-pipelines i skarpt läge.

## Viktigt
Det heter "Studerande", inte "elev" eller "studerande"
Då det är en utbildning börjar vi från enkla "int x=3" till senare "var x=3" men alltid från enkel och ökar svårigheten succesivt mellan övningarna.
