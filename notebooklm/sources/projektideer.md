# Projektidéer för Cloud Developer-studerande

Fastnat? Vill öva mer? Välj ett projekt som passar din nuvarande kursnivå.
Tumregel: om det känns lite för svårt — perfekt, det är precis rätt nivå.

## Kurs 1–2: Konsolapplikationer i C# (nybörjare)

Fokus: grundläggande OOP, loopar, villkor, klasser, arrayer, grundläggande SQL.

| Projekt | Vad du tränar |
|---------|---------------|
| Gissa ett tal | Random, loopar, if/else |
| Miniräknare | Metoder, switch, felhantering |
| Temperaturomvandlare | Klasser, enums, konvertering |
| Ordgissningsspel (Häng-gubben) | Strängar, arrayer, loopar |
| Quiz-applikation | Listor, klasser, filläsning |
| Kontaktbok (konsolbaserad) | Listor, CRUD-logik |
| Bankkontosimulatorn | OOP, arv, inkapsling |
| ATM-simulator | Klasser, validering, loopar |
| Valutaomvandlare | API-anrop (enkel) |
| Filbaserad anteckningsapp | Filhantering, listor |

## Examensarbete — projektidéer

Välj något du faktiskt bryr dig om. Det märks i rapporten om du inte gör det.

| Projekt | Varför det fungerar som examensarbete |
|---------|---------------------------------------|
| Automatiserad deployment-pipeline (IaC + CI/CD) | Täcker Terraform, GitHub Actions, Azure, säkerhet — hela programmet |
| Containeriserad mikrotjänstarkitektur | Docker, Kubernetes, API-design, monitorering |
| Realtidsövervakning med alerting | Grafana, Azure Monitor, Kubernetes — praktiskt och mätbart |
| Serverless-applikation på Azure Functions | Modernt arkitekturval med tydlig motivering att diskutera |
| DevSecOps-pipeline med automatisk sårbarhetsskanning | Säkerhet + CI/CD + dokumentation = stark rapport |
| AI-integrerad cloud-applikation | Aktuellt, motiverbart, API-konsumption i praktiken |
| Migrera en monolitisk app till microservices | Arkitekturskifte med tydliga fördelar/nackdelar att reflektera över |
| Egenutvecklad CLI för molnautomation | Visar djup förståelse för plattformen och CLI-design |
| Privat Kubernetes-kluster med full CI/CD | Ambitiöst, men möjligt med 5 veckor och bra planering |
| LIA-kopplat projekt (med arbetsgivarens godkännande) | Bästa scenariot — verkligt problem, verklig miljö |

> 💡 **Tips:** Det bästa examensarbetet löser ett problem du faktiskt stötte på under LIA eller kurserna. Fråga dig: "Vad önskade jag fanns?"

## 📓 Om TIL-journalen och examesrapporten

Din TIL-journal är inte bara anteckningar — den är råmaterialet till examesrapporten.

**Från kurs 1:** Skriv varje dag du kodar, även en rad räcker.
**Under LIA:** Varje dag är ett potentiellt kapitel. Missa inte en dag.
**Under examensarbetet:** Skriv parallellt med koden, inte efteråt.

En studerande som skrivit TIL konsekvent sedan kurs 1 har redan halva rapporten klar när examensarbetet börjar.
