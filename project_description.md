## Vad det är

Ett AI-workspace paketerat för studerande i Cloud Developer-programmet (CLO26) på YRGO/Campus Mölndal.
Innehåller konfigurationer för fem olika AI-verktyg — Claude Code, OpenAI Codex CLI, Gemini CLI,
opencode och Google NotebookLM — alla med samma "Virtuell Marcus"-persona: en sokratisk lärarassistent
som ställer frågor istället för att göra läxorna åt studerande.
